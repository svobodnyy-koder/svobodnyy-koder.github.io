# Neurodeck · Anatomia ativa

Site estático de estudos construído a partir de **Neuroanatomia - Imagens Principais.pdf**.

## Executar no macOS — sem npm

No Terminal:

```bash
cd /Users/igor/Documents/Projetos/neuroanatomia
python3 -m http.server 4173
```

Abra http://localhost:4173.

Também é possível dar duplo clique em `start.command` para iniciar o servidor e abrir o navegador automaticamente.

O atlas contém as 49 pranchas renderizadas do PDF e o treino contém 115 questões (36 fáceis, 38 médias e 41 difíceis).

As imagens ficam em `assets/prancha-01.jpg` até `assets/prancha-49.jpg`.
